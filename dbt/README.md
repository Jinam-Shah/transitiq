# dbt (gold layer)

dbt-duckdb project that turns the silver views into the gold star schema. Runs in the `pipelines`
Docker container (D-016); `DBT_PROJECT_DIR` and `DBT_PROFILES_DIR` are preset there.

```powershell
docker compose run --rm pipelines transitiq-silver publish
docker compose run --rm pipelines dbt build
docker compose run --rm pipelines dbt docs generate --static
```

- `models/staging/` - views over `silver.*` (sources.yml is generated from the silver contracts and checked by `tests/test_dbt_contracts.py`)
- `models/marts/core/` - dimensions and facts (enforced contracts + tests)
- `models/marts/reliability/` - reliability marts
- `seeds/holidays.csv` - generated by `scripts/make_holidays.py`
- `tests/generic/` - `positive`, `between`, `unique_combination`, `expression_is_true`
